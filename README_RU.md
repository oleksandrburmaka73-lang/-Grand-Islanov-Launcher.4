# Grand Islanov RP — стартовый Android-проект

Это первая рабочая оболочка лаунчера: HTML-интерфейс внутри Android WebView и сборка тестового APK через GitHub Actions.

## Сборка с телефона
1. Распакуй ZIP.
2. Создай репозиторий GitHub и загрузи **все содержимое папки проекта** в корень репозитория (не сам ZIP).
3. Открой Actions → Build Grand Islanov APK → Run workflow.
4. После успешной сборки скачай Artifact `Grand-Islanov-RP-debug-apk`; внутри будет `app-debug.apk`.

## Важно
- Пока это оболочка лаунчера, а не готовый игровой клиент.
- Кнопка запуска пытается открыть установленное приложение по `samp://`; нужен клиент, который понимает этот адрес.
- Вход, реальный онлайн, новости с сервера и автообновление пока демонстрационные/не подключены. Не вводи настоящие пароли в демо-форму.
- Старый APK сохранён отдельно и не изменяется. Из APK нельзя автоматически восстановить полный исходный Android Studio-проект; интеграцию его библиотек нужно делать отдельно после проверки совместимости и прав на компоненты.
